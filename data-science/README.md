# Data Science

Scratch work, research notebooks, and supporting assets for the credit scoring project.

## Contents

| Path | Description |
|------|-------------|
| `Machine Learning Automation of Loans Approval.ipynb` | Original ML notebook — RF, XGBoost, LGBM evaluation |
| `SQL Reports.ipynb` | Back-office SQL queries (collections, PTP, cashflow, disbursements) |
| `assets/` | Charts, PDFs, and figures generated during analysis |

## Notes

- The production ML code lives in `credit-scoring-platform/backend/app/ml/`
- The production SQL logic has been ported to FastAPI routers in `credit-scoring-platform/backend/app/routers/`
- Use this folder freely for experiments, EDA, model comparisons, and one-off analysis
